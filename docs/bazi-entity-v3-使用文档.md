# bazi-entity-v3 使用文档

> 一套可复用的「四柱八字 × 万物」分析 skill，供任何 AI agent（Codex 等）调用。
> 人与游戏/产品/公司共用同一套底层模型，只用一个 `entity_type` 参数切换。
> 定位：文化娱乐性质的模型推演，不作科学预测，不作为投资、医疗或婚恋决策依据。

## 1. 这是什么

`bazi-entity-v3`（万物命理）是精读《千里命稿》《子平真诠》《滴天髓》三书及梁湘潤今註后重构的 **v4 模型**，固化为 Codex skill：

- 确定性排盘：脚本计算四柱、纳音、藏干、十神、十二长生、常用神煞、大运、流年。
- 六模块管线：根气 → 格局（成败/相神/带忌救应）→ 体用喜忌 → 气象调候（源流/通关/寒暖燥湿）→ 时序（大运成格变格/流年干支并看/岁运战冲和好）→ 实证校准。
- 层次原则：强弱 < 格局 < 气象 < 调候；神煞不作格局依据；结论概率化、可证伪。
- 实体感知：人（70—90 年）、游戏（5—15 年）、产品（5—20 年）、公司（20—100 年）各自有寿命缩放与输出轴。
- 证据纪律：只把“事前、可查证”的预测计入命中率，事后复盘不算数。

## 3. 如何调用

### 人类用户

- 人盘：> 用 bazi-entity-v3 分析我的八字，出生 1995-06-15 08:30（UTC+8，女），重点看事业和婚姻。
- 游戏/产品：> 用 bazi-entity-v3 分析《XXX》，公测 2024-09-26 10:00（UTC+8），输出热度、寿命关口和可验证判据。

### AI agent

- 显式调用：`$bazi-entity-v3`
- 触发词：八字/命理/算命 + 人/游戏/产品/公司；预测运势/热度/流水/倒闭时间；版本锚分析；校准历史预测。

## 4. 排盘脚本（通用）

纯 Python 3 标准库，无需安装依赖。人、游戏、公司通用：

```bash
python scripts/pai_pan.py "2024-05-23 10:00" --name 鸣潮 --lucky 10 --years 12
python scripts/pai_pan.py "1990-01-01 10:00" --name 示例人盘 --gender female --lucky 10 --years 12
python scripts/pai_pan.py "2017-03-02 10:00" --name 某公司实体 --json
```

参数：

| 参数 | 说明 | 默认 |
|---|---|---|
| `datetime` | 本地时间 `YYYY-MM-DD HH:MM` | 必填 |
| `--name` | 对象名（显示用） | 空 |
| `--tz` | UTC 偏移小时 | 8 |
| `--gender` | `male` / `female`，决定大运顺逆 | male |
| `--lucky` | 输出大运数量 | 10 |
| `--years` | 输出流年数量 | 8 |
| `--json` | 输出结构化 JSON | 关 |

已验证案例（与万年历/官方时刻核对）：

| 输入 | 输出 |
|---|---|
| 2024-05-23 10:00 | 甲辰 己巳 丁亥 乙巳，顺排，交运 2028-10-03，首运庚午 |
| 2025-01-02 10:00 | 甲辰 丙子 辛未 癸巳 |
| 2017-03-02 10:00 | 丁酉 壬寅 戊子 丁巳，逆排 |
| 1990-01-01 10:00（女） | 己巳 丙子 丙寅 癸巳，顺排（阴年女） |

节气算法精度：太阳黄经截断模型，与官方节气时刻误差约 5 分钟（1900—2100 适用）。

## 6. 四层模型速览

1. **L1 气学坐标**：任何实体的“出生时间”都是接气锚点；主锚＋次锚（大版本/产品线）＋可选锚（公司实体）互证。
2. **L2 体用格局**：体＝日主（本体），用＝财官/调候；旺衰管温度，做功管骨架。
3. **L3 象法应期**：定寿元星 → 找冲穿制绝窗口；查库象、用神化忌/受制、天地合、伏吟、纳音伏吟；半定量档位用行业口径校准。
4. **L4 实证校准**：证据分 A/B/C 三级，只统计 A 级命中率，季度回填、权重迭代。

人盘额外读 `references/human.md`：六亲映射（印=母、财=妻/父、官=夫/事业、食伤=子女等）、六大分析轴、大运人生阶段、隐私纪律。

## 7. 寿命缩放（实体感知）

统一规则：寿元星三关（一创＝重伤可过；二创＝衰退；三创＝大限），大运刻度 10 年不变，但主程与暮年窗口随类型缩放：

| 类型 | 主程 | 大限窗口 |
|---|---|---|
| human | 前 6—7 步大运（少年到晚年） | 第 8 步以后 |
| game | 前 2 步 | 第 10—13 年 |
| product | 前 2 步 | 第 10—15 年 |
| company | 前 4—6 步 | 第 6 步以后 |

## 8. 校准工作流

每次分析后，把输出判据写入 `references/calibration.md` 的待验证清单：

- 每条判据含：时间窗、判定标准、数据源。
- 到期回填 `hit / miss / pending`。
- 连中 2 次上调权重；偏差 2 次下调并写替代解读。
- 人盘校准注意脱敏：不存姓名与精确生日，只存事件、类别、应验度。

鸣潮完整示例（8 条已应验事件、6 条待验证判据）已内置在 `references/calibration.md`。

## 9. 已知边界与约定

- 默认 23:00 换日（子初换日）、UTC+8；human 用真实性别，game/product 默认 male。
- 节气时刻存在约 ±5 分钟误差；出生时间临近节气边界时需人工复核。
- 命理判断不构成事实陈述；事件、流水、销量必须引用公开来源。
- 人盘敏感内容（健康/婚姻）只输出给当事人，不做持久化推论。

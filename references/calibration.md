## 1. 记录 schema

每条记录：

```yaml
- id: C-001
  date: 2024-05-23
  event: 开服技术事故、差评风暴、官方补偿
  model_reading: 巳亥冲、官星受损、劫财夺食 → 开服即大劫
  evidence: A/B/C
  verdict: hit | miss | pending
  weight_effect: +0.1 巳亥冲=变革引擎
  source: 公开报道/官方公告
```

季度回填；只统计 A 级命中率。命中率 = A级命中 / A级已到期判据。

v4 新增：每条判据挂接“所依赖假设”（如“格局=食神生财”“调候需水”）；偏差时按 M2/M3/M4 归因，先更新假设再调权重。

v6 新增——**断语三级制**：

- S 级（结构化规则）：由干支生克/格局/岁运关系推导，多书一致，可作结论骨架。
- C 级（文化注记）：神煞、纳音、歌诀、体象诗、择吉吉凶。输出必须标注"文化注记"。
- X 级（不采用）：历史性别观断语（娼淫/奴婢/克夫）、医疗断语、生肖/日支定生死
  的小儿关煞。**X 级禁止出现在最终输出**，用户要求史料引用时须加说明。

**多书互证**：关键格局/岁运结论至少两书一致；冲突时按门派分歧并列并注明出处。
判断时先问"这条断语是哪一级"：S 级可直接用于结论，C 级只能作旁证，X 级直接剔除。

人盘校准（human）：

- 记录脱敏：`1990-01-01 10:00（UTC+8，女）`，不存姓名。
- 事件类别：事业/婚恋/健康/子女/学业/财务。
- 判据面向当事人回访：如“2027 丁未年有事业变动”，以当事人确认为准。
- 同一事件只记一次，不做事后改写。

## 2. 权重调整规则

- 连中 2 次 → 上调权重并写明适用边界。
- 偏差 1 次 → 记录；偏差 2 次 → 下调并写替代解读。
- 同一五行至少观察 2 个流年再改喜忌。
- 版本锚事件与主锚同向 → 主判断置信度 +1 档。

- L2 体用：丁火帝旺双巳，体旺；用＝庚金（财，长生在巳，藏而不透）、壬水（官，坐亥被双巳冲）。做功＝食神生财（内容驱动）＋官星受冲（争议出圈）。

## 4. 判据写法要求（v5 新增）

每条判据必须同时给出**基线概率**与**判死条件**，否则不计入 A 级：

- `base_rate`：不用本模型、仅凭行业常识的发生概率。例如"运营中的手游年内会有一次
  重磅企划官宣"接近 100%，这类判据即使命中也无信息量，须重写或加严阈值。
- `falsify`：什么情况明确算失败（含过期未发生即 miss）。
- `deadline`：回填截止日。
- `assumptions`：所依赖的格局/体用/调候假设，偏差时按 M2/M3/M4 归因。

判据只有在 **预测概率显著偏离 base_rate** 时才算模型给出了信息；命中率须与
基线命中率并列报告，见 `scripts/verify.py`。

## 5. 同盘异命与输入精度纪律（v7.1 新增）

### 古典依据（原书原文）

- 《三命通会》卷四「论五行时地分野吉凶」：**"今之谈命者，但知论阴阳五行
  而不知兼论方隅与昼夜阴晴，所以有年日月时同而贵贱寿夭迥异，便谓五行无据……"
  又云"人禀天地灵气以生一时，得气各自不同，所以贵贱寿夭难以八字拘也。"**
  即古人自己承认：单凭八字不能定命，须并入出生地域（九州分野）、昼夜阴晴。
- 《滴天髓》「生时」章原注：**"至同年同月日而百人各一应者，当究其时之先后，
  又论山川之异，世德之殊，十有九验。"** 区分维度：出生时刻先后（分秒/交运）、
  山川（地域风气）、世德（家世与时代）。
- 《神峰通考》：**"山川风气，平日所产人物可如……古云生江南则为橘，生江北则为枳。"**

### 模型处理

1. **同盘异命是预期，不是模型 bug**：八字只编码出生时刻的部分信息；
   地域、家世、时代、后天选择不在四柱内。
2. **登记要求**：判据必须登记出生地经度与时刻精度（A/B/C 级）；
   C 级（时辰占位）的盘，时柱、命宫、胎元、起运点不得进入结论。
3. **占位会制造假同盘**：2026-08 用 20 位名人验证发现，林肯/达尔文
   "同盘"（己巳 丙寅 己未 庚午）源于两人时辰均无记载、以正午占位；
   真实时辰若不同（如 10 时 vs 12 时），四柱即不同。**引用该反例时必须标注
   "时辰占位，同盘存疑"。**
4. **同盘对比工具**：`scripts/compare_charts.py` 输出两盘全部模型内差异
   （真太阳时、交运日差、大运表、命宫、胎元、±3h 时辰敏感性），
   校准登记与同盘分析前先跑一遍。

### 区分维度清单（同盘时按此逐项检查，均为低置信解释变量）

| 维度 | 出处 | 说明 |
|---|---|---|
| 时之先后 | 滴天髓生时章 | 出生分秒不同 → 真太阳时/交运不同 |
| 山川之异 | 滴天髓、三命通会、神峰通考 | 九州分野：木喜兖青、火喜徐扬、金喜荆梁、水喜冀雍、土喜豫 |
| 世德之殊 | 滴天髓生时章 | 家世、时代、环境 |
| 昼夜阴晴 | 三命通会时地分野 | 晴雨冷暖改变调候权重 |
| 时辰可信度 | 校准纪律 | 占位时辰产生的四柱不可作证据 |

# 20 位明确出生时刻名人排盘检验（2026-08，v7.5）

> 引擎：BFFT v7.5（性能优化 + famous20 数据文件化 + 独立参照逐柱比对）
> 性质：**排盘引擎正确性检验，不是命理预测验证**。名人回测无法证明模型"算得准"，
> 只能证明"排盘与独立实现一致"。事后拟合无信息量的论证见 §6。
> 复现：
> ```bash
> python scripts/famous20.py            # 排盘表
> python scripts/famous20.py --check    # 与独立参照逐柱比对（退出码 0=全过）
> node scripts/famous20_reference.mjs   # 重新生成独立参照（需 npm 装 lunar-javascript）
> ```

## 1. 结论先行

1. **20 位名人全部有明确出生时刻**：评级 A（自传/新闻报道）或 AA（出生证），
   无 C 占位、无 DD 冲突样本；出生时刻与评级来自 astrotheme.com
   （Astro-Databank 体系），历史时区（夏令时/战时时间/LMT）另与 astro-charts.com
   交叉核对，每条数据带来源 URL。
2. **四柱逐柱比对 20/20 通过**（80 柱位）：年柱 20/20、月柱 20/20、日柱 20/20、
   时柱 20/20。其中时柱有 6 例是"真太阳时口径差异"（引擎按真太阳时取时支，
   独立参照按钟表时刻取时支），用「参照日干 + 引擎真太阳时时支」复算五鼠遁后
   全部吻合——不是 bug，是 v5 起的设计使然（§4）。
3. 这 6 例恰恰说明**时柱对"用哪个时间"极其敏感**：乔布斯钟表时 19:15 报戌时、
   真太阳时 18:51 报酉时；威廉王子 21:03 报亥时、真太阳时 20:00 报戌时。
   时辰不明确或时区/夏令时标错的盘，时柱可能整根错。
4. **排盘正确 ≠ 预测有效**。本检验只回答"引擎是否与独立实现一致"；
   "命理准不准"仍只能靠 predictions/ 的事前登记 + 技巧分数，不能用名人回测证明。

## 4. 逐柱比对与 6 例"真太阳时口径差异"

参照实现：lunar-javascript（6tail，与 python 版 lunar_python 同源），口径——
年/月柱用 UTC+8 绝对时刻 + `get*InGanZhiExact()`（节气精确切换）；日柱取出生地
民历日；时柱取出生地钟表时刻（五鼠遁）。比对结果：

| 柱位 | 一致 | 说明 |
|---|---|---|
| 年柱 | 20/20 | 立春切换全部一致 |
| 月柱 | 20/20 | 12 节切换全部一致 |
| 日柱 | 20/20 | 与独立日柱表完全一致 |
| 时柱（直接） | 14/20 | 6 例差异全部可解释（下表） |
| **时柱（复算后）** | **20/20** | 见下 |

6 例差异 = 真太阳时把钟表时刻拖过时辰边界，两方口径不同但都"对"：

| 姓名 | 钟表时刻（参照时支） | 真太阳时（引擎时支） | 引擎时柱 |
|---|---|---|---|
| 乔布斯 | 19:15 戌 | 18:51:59 酉 | 丁酉 |
| 戴安娜王妃 | 19:45 戌 | 18:43:15 酉 | 乙酉 |
| 威廉王子 | 21:03 亥 | 20:00:36 戌 | 丙戌 |
| 奥巴马 | 19:24 戌 | 18:46:37 酉 | 癸酉 |
| 保罗·麦卡特尼 | 14:00 未 | 11:47:15 午 | 丙午 |
| 卡玛拉·哈里斯 | 21:28 亥 | 20:34:14 戌 | 庚戌 |

复算规则：`参照日干 + 引擎真太阳时时支 → 五鼠遁`，6/6 与引擎时柱一致。
结论：**没有发现引擎 bug**；但任何"报钟表时刻不报经度/不核夏令时"的第三方八字站，
都会在这 6 人上与本站结果不同——引用外部对照时先对齐时间口径。

## 5. 本版引擎优化（v7.5）

| 优化 | 内容 | 效果 |
|---|---|---|
| IDX60 查表 | 60 甲子序号从 O(60) 线性查找改为模块加载时建表 O(1) | 全部柱位/大运路径提速 |
| solar_correction 合并 | 真太阳时的 JD/均时差/经度修正一次算好，to_solar_time 与 to_true_solar 共用 | 每盘少算一次均时差 |
| jie_list 缓存 | `@lru_cache` + 返回 tuple（一次 calc 会重复请求前后三年的节令） | 批量排盘复用 |
| 神煞内层查表 | 天乙/禄/文昌/羊刃/三合局先归并成局部常量 | 内层循环零重复 index/get |
| famous20 数据文件化 | 出生数据、来源、评级、参照四柱全部进 `data/famous20_times.json` | 数据可审计、可复现 |
| `--check` 独立比对 | 新增逐柱比对与真太阳时口径复算，差异退出码 1 | 回归护栏（tests 已固化） |

基准（同一批 300 盘，E:\python 3.13）：0.44 ms/盘 → 0.34 ms/盘（约 23% 提速）；
测试 62 → 71 条，全部通过（0.06s）。

## 6. "效果好不好"的诚实回答

- **排盘正确性：好。** 与独立实现 80/80 柱位一致，6 例时柱差异有明确口径解释。
- **命理有效性：无法用本测试证明。** 这 20 人都是"成功者"样本（幸存者偏差），
  事后用八书规则给任何人生都能写出相容叙事（旧 v7.1 验证 20/20 相容，
  而 100% 相容恰说明规则库过宽、无区分度）。唯一的可证伪证据链仍是
  `predictions/` 事前登记 + `verify.py` 技巧分数。
- **模型层结论不变**：同盘异命（林肯/达尔文占位案例）、相似盘异命、
  异盘同命的边界写入 calibration.md 第 5 节；时辰占位盘不得进入结论。

## 7. 已知问题

- LMT（莫扎特/爱因斯坦/希特勒）按 `lon/15` 近似，未做当地历史授时考证，
  时柱按真太阳时输出后对 LMT 误差不敏感，但年/月柱边界附近仍需核对。
- 哈里王子为 A 级（新闻报道），astro-charts 未收录时刻；若后续找到出生证可升 AA。
- 独立参照的时柱按钟表时刻口径；想复现"钟表时派"结果，把 `--check` 里
  ✓* 行对应的时柱换成参照时柱即可。

## 1. 与游戏/产品盘的异同

相同：排盘（scripts/pai_pan.py）、四层架构（L1 锚点 = 出生时间；L2 体用格局；L3 寿元星/冲穿制绝/库象/天地合/伏吟；L4 校准）。

不同：

- 寿命标尺 70—90 年，大运 10 年对应真实人生阶段，不是行业寿命缩放。
- 输出轴从“热度/流水/关服”换成“事业/财运/婚姻/健康/子女/学业”。
- 校准数据源是本人反馈（隐私），不是公开流水。
- 起盘性别用真实性别；换日时辰争议（23:00 子初换日 vs 0:00）需声明。

### v6 六亲增量（八书贯通后）

- **明干取/暗中求**（《三命通会》）：六亲星透干先用透干，无透看支中藏干与坐支。
- **喜神看财、喜神看官杀**（《滴天髓》夫妻/子女章）：妻、子不按固定十神定性，
  而看喜忌语境——喜神即财神则妻贤，喜神即官星则子贵；官杀清而身旺者贵。
- **宫位＋星位双轨**：年祖业、月父母兄弟、日妻妾己身、时子息（宫位法）与
  印母/财父/官杀子女/比劫兄弟（星位法）并列；冲突时按门派分歧输出。
- **旧书性别断语中性化**：《三命通会》《渊海子平》《神峰通考》中"娼淫、奴婢、克夫、
  旺夫益子"等断语是历史性别观的产物，**不采用**。保留其结构内核：
  官杀＝权威约束关系、食伤＝产出表达关系、时上引归＝关系落点。
  女命章以《滴天髓》"论夫论子要安详，气静平和妇道章，三奇二德虚好语"为范本：
  不专执官星论夫、不专执伤食论子，以格局喜忌为准。

## 3. 六大分析轴

- 事业：官杀（地位/压力）＋财（回报）＋印（资质/平台）。官星透干得生 = 有名分；官杀混杂 = 多线压力。
- 财运：财星与食伤生财做功；财入库 = 能存钱，财透大运 = 得财窗口；比劫夺财 = 破耗/合伙纠纷。
- 婚姻：男看财星与日支（妻宫），女看官杀与日支（夫宫）；宫星被冲/合 = 感情波动；伏吟日支 = 婚恋反复。
- 健康：五行过旺/过弱与克泄交加；火炎 = 心血管/炎症，水旺 = 肾/泌尿，金木交战 = 筋骨/肝胆，土重 = 脾胃。
- 学业：印星＋文昌贵人；印被合/被克 = 考试波动；食伤吐秀 = 才华型学习。
- 子女：男看官杀，女看食伤；时柱为子女宫；时柱逢冲/伏吟 = 子女缘波动。

## 4. 大运人生阶段

| 大运序号（约年龄） | 阶段 | 重点 |
|---|---|---|
| 1（0—10） | 童蒙 | 印比为主：家庭、体质、启蒙 |
| 2—3（10—30） | 求学/立业 | 印、食伤、财官：学业、初恋、入行 |
| 4—5（30—50） | 打拼/成家 | 财官：事业、婚姻、置业、子女 |
| 6（50—60） | 守成/调整 | 官杀食伤：压力与转型 |
| 7（60—70） | 颐养/名誉 | 印食：健康、传承、声望 |
| 8+（70+） | 晚年 | 寿元星三关窗口 |

阶段是参考线，必须结合原局喜忌与用神判断，不能只看年龄。

## 5. 寿命与三关

- 寿元星 = 贴身之体（通常日支坐支藏干；官印一般不取）。
- 三关：第一重创（冲穿制绝）＝大劫（伤病/大事件，可过）；第二＝衰退/健康转折；第三＝大限。
- 大限窗口优先看：日主入墓/绝地之年、寿元星被制尽之年、伏吟再现之年（如原局巳亥冲，逢巳/亥年多波动）。
- 有库护寿元（如辰收亥水）＝底子厚、难有横祸。

## 6. 流年应期提示

- 冲：动（搬家、换工作、婚变、远行）。
- 合：成（合作、婚恋、签约、买房）；天地双合 = 大事件。
- 穿/破：暗损（小人、破财、纠纷）。
- 伏吟：循环（旧事重演、回到原点）。
- 墓库：收藏（存钱、沉淀、也可能是压抑）。
- 桃花/咸池：感情缘、出圈、绯闻。

## 7. 隐私纪律

- 不落盘姓名、精确生日等可识别信息；用“1990-01-01 10:00（UTC+8，女）”或干支直接记录。
- 校准记录只保存：事件年月、事件类别（事业/婚恋/健康）、应验度。
- 敏感内容（健康/婚姻）只输出给当事人，不做持久化推论。

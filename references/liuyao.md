# 六爻平行模块（v7.15 整合）

> 六爻与四柱是**平行体系**：本模块只做排盘（装卦）与格局标注，
> 解卦结论一律按 BFFT 全局纪律输出——事前判据、禁伪精确、断语分级，
> 不因换体系而放松。

## 使用

```bash
# 手动六爻编码（1=少阴 2=少阳 3=老阳动 4=老阴动，自初爻至上爻）
python scripts/liuyao_cli.py --yao "123121" --dt "2026-08-16 23:00" --subject 问事

# 三币随机摇卦
python scripts/liuyao_cli.py --random --dt "2026-08-16 23:00" --json
```

## 关键改造：月建日辰精确化

原 xiongdun8/liuyao 用固定日期表判断月建（如立春固定 2/4），
节气时刻年际浮动会造成边界日装错月建。本模块改用 BFFT 引擎的
节气精确计算（牛顿迭代求根 + ΔT 修正），六爻的"月建/日辰"与四柱
"月支/日支"同源，排盘口径统一。

## 纪律（与四柱一致）

- 起卦时间=锚点，须可复核；摇卦随机性不赋予因果意义。
- 解卦输出只给倾向与条件句；"某月必成/必败"类断言禁止。
- 关键事件预测走事前判据（predictions/ 登记，base_rate/falsify/deadline）。
- 健康/医疗、司法类问题不输出结论（X 级）。
- 输出声明：娱乐参考，不作决策依据。

# BFFT 模型规范 v5（三书融合 · 现代工程化）

## 0. 版本定位

v4 由精读三书后重构：

- 《千里命稿》（韦千里）：实用批命格式、用神/相神、旺衰病药、流年月建干支并看、六亲救应。
- 《子平真诠》（沈孝瞻）：格局体系（专求月令）、成败救应、相神、纯杂高低、变化、调候、墓库刑冲、生克先后、星辰无关格局、行运成格变格。
- 《滴天髓》（京图/任铁樵）：理气、体用、精神、源流、通关、寒暖燥湿、众寡、顺逆、从化、战合、清浊、真神假神、隐显、贞元、何知章。
- 梁湘潤《今註》：月支本气定格、强弱非第一要义、调候可超越中和、用神十四制式、病药三分（伤用神/伤喜神/伤格局）。

v4 原则：**强弱 < 格局 < 气象 < 调候**，层次分明；结论概率化、判据可证伪、偏差可归因。

### v5 相对 v4 的变化（模型层不变，工程层修正）

v5 沿用 v4 的全部理论体系（三书融合、六模块、层次原则），改动集中在排盘引擎与
可证伪机制：

1. **真太阳时**：新增经度修正与均时差。此前同一时区内不同经度共用一套时柱，
   东八区极端情况可差 2 小时 15 分，时柱整根错位。人盘必须提供出生地经度。
2. **中国夏令时 1986—1991**：自动识别并回拨 1 小时。
3. **换日流派可切换**：`--day-boundary zi|midnight`，并在输出中并列另一派日柱，
   兑现"门派分歧并列、不作独断"这条纪律（此前换日规则是硬编码单派）。
4. **修正流年干支分界**：改为以立春为界（此前直接用公历年，与年柱逻辑矛盾，
   年初一个多月的流年会错一位）。
5. **ΔT 修正与时刻精度**：黄经公式吃的是 TT，此前当 UT 用；节气时刻此前截断取整。
6. **不变量测试**：`tests/` 用节气回代黄经、月柱进位、日柱递增、大运连续性等
   自校验守住重构；绝对精度校验留 `tests/fixtures.csv` 供填权威万年历样本。
7. **预测登记**：`predictions/` 以 git commit 时间戳作为"事前"证明，
   使判据可升为 A 级证据；`scripts/verify.py` 统计命中率与 Brier 分数，
   并强制要求每条判据写明基线概率（base rate）。

## 1. 六模块管线（M1—M6）

### M1 排盘与根气

- 排盘：沿用 scripts/pai_pan.py（节气、大运、流年）。
- 根气判定（《子平真诠·论十干得时不旺失时不弱》）：
  - 得时不旺：月令当令但四柱克泄太重。
  - 失时不弱：月令休囚但年月时得禄旺长生。
  - 根重次序：长生禄刃 > 墓库余气 > 比肩（得一比肩不如得一墓库，得三比肩不如得一长生禄刃；阴长生弱于阳长生）。
  - 天覆地载：干喜有支根、支喜有干透，干支不反悖。
- 生时归宿（《滴天髓·生时》）：时柱为归宿，人元用事深浅影响后半生与子女宫。

### M2 格局引擎（《子平真诠》为主）

- 取格：专求月令。本气不透亦定格，透干者附格（梁湘潤法：月支本气对日主定格，天透地藏之字可成另格）。
- 顺逆：财官印食顺用，煞伤劫刃逆用；当顺而顺、当逆而逆。
- 成败：按八格列出成格条件与败格条件。
- 带忌/救应：成中有败看带忌，败中有成看救应。
- 相神：凡全局赖此一字而成者皆相神；**伤用神甚于伤身，伤相甚于伤用**。
- 纯杂、高低：用神纯者吉杂者凶；格局高低看有情有力。
- 变化：透干/会支改格；变之善、变之不善、变而不失本格；因成得败、因败得成。
- 杂气：透干会支取其清者；有情无情、有情卒无情、无情终有情。
- 墓库刑冲：**四墓不忌刑冲，刑冲未必成格**；土冲则灵，财官属水者冲则反累；不取“入库必冲”俗说。
- 外格：月令有用神则不用外格（提纲有用提纲重）。
- 星辰：**神煞不参与格局成败**，只作取象/应期辅助（修正 v3 神煞权重）。

### M3 体用与喜忌

- 多级体用（《滴天髓·体用》）：日主为体提纲为用；四柱为体岁运为用；喜神为体辅喜神为用；格象为体日主为用。输出时注明采用哪一级。
- 用神（《千里命稿》）：助格局成功、救格局破败、抑格局太过、扶日主之弱；用神得力为上、不得力为下、无用神更下。
- 相神（千里/子平双证）：生助用神或解救用神之字，与用神同等重要。
- 强弱权重（梁湘潤）：日主强弱不是第一要义；财印出干与否、格局顺逆往往优先。
- 病药三分：伤用神、伤喜神、伤格局，三者分别论药；调候不宜为病、强弱可为病。
- 吉凶神相对论（《子平真诠》十八、十九）：四吉神可破格、四凶神可成格；吉凶喜忌全在是否合于需要。

### M4 气象与调候（《滴天髓》为主）

- 源流：取最多最旺者为源头，看流向何方、何处为归路、何处阻节；归路为喜则富，阻节之神断休咎。
- 通关：两神相战，中间需通关之神（木土要火、火金要土、土水要金、金木要水、水火要木）；通关非普适，须验其力（梁湘潤提醒）。
- 寒暖燥湿：过寒需暖、过暖需寒、过湿滞而无成、过燥烈而有祸；调候为急可超越中和。
- 众寡：强众敌寡者势在去寡；强寡敌众者势在成众（从格/专旺依据）。
- 顺逆从化：气势已成可顺不可逆；真从论从、假从可发；真化论化、假化亦贵。
- 清浊：一清到底有精神；澄浊求清；半清半浊多成多败。
- 真神假神：令上寻真，假神不乱真神；提纲不照时暗处寻真。
- 隐显：吉神太露起争夺，凶物深藏成养虎；忌神明透制化得宜者吉。
- 形象方局：两气成象不可破、独象喜行化地、全象喜行财地；形全损余、形缺补不足；方局不可混。
- 战局合局：天战犹自可、地战急如火；合有宜不宜，合多不为奇。

### M5 时序引擎（大运·流年·月建）

- 干支并看（《千里命稿》）：流年/月建干支各 12 条交互规则；月干重于月支。
- 行运同命法（《子平真诠·论行运》）：喜忌、似喜实忌、似忌实喜、行干不行支、支同不两行、冲分缓急轻重、逢冲不冲、一冲两冲。
- 成格变格：运可成格变格，关系甚大，优先级高于一般喜忌。
- 透清：支中喜忌逢运透干/会局方验；逐干逐支上下统看，支为干之生地、干为支之发用。
- 岁运战冲和好（《滴天髓·岁运》）：运伐岁/岁伐运、冲、和、好四类关系定休咎。
- 贞元：年为元、月为亨、日为利、时为贞；大运初十五年/次十五年/中十五年/后十五年；产品/公司加“代际继承”读法（父为贞、子为元）。
- 寿元星（保留 v3）：贴身之体；三关读法；库护寿元难杀。

### M6 实证校准

- 证据分级 A/B/C（保留 v3）；只计 A 级命中率。
- 新增“假设—反证”机制：每条判据挂接其依赖的喜忌/格局假设；偏差时先查 M2/M3/M4 哪一层假设被证伪（滴天髓“恩怨闲疑”）。
- 概率化：结论带置信度（高/中/低）与条件句（若…则…）。
- 多方案输出：主方案（默认取法）＋备选方案（他派取法）＋分歧点，避免门派独断。

## 3. 现代思维升级清单（v3 → v4）

1. 强弱降权：从“身强身弱优先”改为“强弱 < 格局 < 气象 < 调候”。
2. 神煞降级：只作取象，不作格局成败（《子平真诠·论星辰无关格局》）。
3. 墓库修正：不再机械“冲开财官库”（《子平真诠·论墓库刑冲之说》）。
4. 相神入模：输出相神与“伤相甚于伤用”的应期。
5. 调候优先：调候为急可超越中和（子平配气候、梁湘潤）。
6. 源流通关：新增源头—归路—阻节分析。
7. 生克先后：同字生克先后不同，吉凶不同（子平二十）。
8. 多级体用：明确体用层级，避免“用神”一词混用。
9. 六亲双轨：并列两派星曜体系。
10. 贞元代际：实体/产品/公司加代际继承读法。

## 4. 输出格式（v4）

1. 排盘与根气表。
2. 格局判定：月令定格、顺逆、成败、带忌/救应、相神、高低、变化。
3. 体用喜忌：层级、用神/相神、病药、调候结论（含置信度）。
4. 气象分析：源流、通关、寒暖燥湿、从化顺逆、清浊。
5. 时序表：大运成格变格、流年干支并看、岁运战冲和好、寿元三关。
6. 判据清单：≥3 条 A 级，含时间窗、判定标准、数据源、所依赖假设。
7. 校准回填：命中/偏差/归因（M2/M3/M4）。

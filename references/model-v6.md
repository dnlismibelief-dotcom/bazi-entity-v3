# BFFT 模型规范 v6（五书贯通 · 现代工程化）

## 0. 版本定位

v6 在 v5 基础上完成**第二轮古籍贯通**：新增五部文献精读
（《三命通会》《渊海子平》《神峰通考》《协纪辨方书》《果老星宗》），
并对 v4 已融合的《千里命稿》《子平真诠》《滴天髓》回头复核。

八部文献的逐书解读、可验证性分级与"不采用清单"见
[classics-v6.md](classics-v6.md)。本文件只写 v6 相对 v5 的模型层增量。

**v6 的立场没有变，且更明确**：这些古籍是前科学时代的诠释体系；
BFFT 把它们当作**结构化规则库与历史文化注记**，不当作科学证据。
所有判据仍必须登记 base_rate，技巧分数 ≤ 0 即视为模型未提供信息。

## 1. M0（新增）：锚点与历法纪律

适用实体：game / product / company 的锚点时间（公测、上线、成立、改名）。

1. **可复核性优先**：锚点时间必须精确到分钟、带时区、来源可查（公告、备案、
   新闻稿）。无法复核的时间宁可不排，不猜。
2. **历法校正**：沿用 v5 引擎的真太阳时（经度＋均时差）、1986—1991 夏令时回拨、
   节气边界告警；距节气 1 小时内的盘必须与权威万年历核对。
3. **择时文化注记（来自协纪辨方书，默认不参与推演）**：若用户主动要求"择日/择时"，
   输出建除、黄黑道等作为文化注记，并明确声明：**择吉神煞对商业结果无因果效力**，
   BFFT 不据此推荐上线日期。
4. **胎元与命宫（来自三命通会，可选输出）**：胎元取生日前 300 日干支；
   命宫按月支逆数＋时支顺数逢卯安宫。默认随 JSON 输出，供"受胎背景/早年根基"
   类结论作低置信参考，不参与格局成败。

## 2. M1 排盘与根气（精化）

v5 已有：天覆地载、根重次序（长生禄刃 > 墓库余气 > 比肩）、得时不旺/失时不弱。

v6 增量：

1. **根重次序补全**（《子平真诠》）：得一比肩 < 支中一墓库（阳干有效）；
   得二比肩 < 得一余气；得三比肩 < 得一长生禄刃。阴长生不作长生论但为明根。
2. **阳干逢库即根，不求冲开**（《子平真诠》批判"投库必冲"、《神峰通考》库要锁钥
   的动静说合并）：身库/根库不作"入库被困"断；冲开只对"库中财官为用且属土"时
   有效（土冲则灵；财官属水冲则反累）。
3. **胎元命宫**（见 M0）：输出为低置信旁证字段。

## 3. M2 格局引擎（增量细则）

v5 已有：月令定格、顺逆、成败、带忌/救应、相神、纯杂高低、变化、杂气、墓库刑冲、
外格用舍。

v6 增量：

1. **十神细则表**（《三命通会》卷五＋《渊海子平》十神专论）：
   - 正官：止许一位；先看月令；支藏干透；忌刑冲破害/伤官七煞/贪合忘官/劫财分福；
     官多则变煞；"逢官看印"（身弱印轻补印、身旺官轻补官）；时上官星力轻发福晚。
   - 偏官：有制为偏官、无制为七煞；"有杀须论杀，无杀方论用"；
     制伏太过为尽法无民（喜行煞旺运）；弃命从杀仅限日主全无根气；
     官杀混杂按去留（合杀留官/合官留杀）处理，不作一律凶断。
   - 伤官：按"伤尽/见官"与五行分化：火土伤官宜伤尽、金水伤官要见官、
     木火伤官官要旺、土金官去反成官、水木伤官财官两见始为欢；
     真伤官（夏木/巳午未月）忌行伤官运，假伤官（春木见火）喜行伤官运；
     伤官用印忌财、用财忌印。
   - 食神：只宜一位；忌枭神（有制合则不畏）；食多宜行印运；
     食神制煞逢枭不贫则夭（除非柱有救应）。
   - 印绶：喜官生（印赖官生）、忌财破；"凡格喜身旺，惟印绶喜生弱"；
     印绶有根喜逢财（财生官、官生印），无根忌见财；弃印就财（偏印月令年时见财无妨）。
2. **杂气取用精化**（《子平真诠》＋《三命通会》）：透干会支取清；
   透与会并重；"有情/无情"以顺生逆背判定；四库喜冲但非冲克之冲；
   财官锁闭少年不发墓中人（透干即解，不需硬冲）。
3. **病药并入格局判定**（《神峰通考》）：月令得格后先找"病"
   （害身/害用/太旺/太弱/雕/枯），再找"药"（损/益/生/长）；
   有病有药且药重者高看，无病无药纯中和者作平常断——与《滴天髓》
   "有病方为贵"一致，但明确这是文化规则而非统计规律。
4. **外格纪律强化**（《子平真诠》"有官莫寻格局"＋《神峰通考》谬说批判）：
   月令有用神时不得弃主格取外格；日贵、魁罡、六壬趋艮、六甲趋乾、
   勾陈得位、玄武当权等"飘空而立"的格名一律不采（在输出中最多作为
   "旧书格名注记"出现）。

## 4. M3 体用喜忌（病药八法）

v5 已有：多级体用、用神/相神、病药三分、强弱降权、四吉神破格/四凶神成格。

v6 增量：把"病药三分"升级为**八法矩阵**（《神峰通考》）：

| 病 | 定义 | 药 | 操作 |
|---|---|---|---|
| 雕 | 精华雕残、泄气太过 | 生 | 行生扶其根之地（如木生亥水滋） |
| 枯 | 气枯无源 | 长 | 行长养其势之地（如财官属木长养寅卯辰） |
| 旺 | 有余 | 损 | 损其有余（用克/用泄） |
| 弱 | 不及 | 益 | 益其不足（用生/用助） |

要点：官旺官多喜食伤制；官弱喜财生官运；身旺财弱喜食伤生财；
身弱财旺喜比劫帮身。行运判断先看盖头（《神峰通考》盖头说）：
运干为盖头，原局所忌之干盖在吉支上，吉支之力亦被压。

## 5. M4 气象调候（八"过"检查表）

v5 已有：源流、通关、寒暖燥湿、众寡、顺逆从化、清浊、真神假神、隐显、
形象方局、战局合局、贞元。

v6 增量（《三命通会》气象篇＋《神峰通考》五星论）：

1. **八"过"检查表**：寒薄（和暖处难发）、燥烈（水激反凶）、执实（用一不通）、
   清冷（思有凄凉）、有情过甚（志无远达）、用力过甚（成亦多难）、
   贵人过甚（逢灾自愈但须看是否真用）、恶煞过甚（遇福难享）。
   分析结论前逐项过表，命中任意一项须在输出中降一档置信度。
2. **四季五行分野**：同一五行在不同季节的喜忌不同（春金喜火暖、夏金喜水润、
   秋金当权、冬金喜火），与调候结合使用，不作死板"身强身弱"二分。

## 6. M5 时序引擎（岁运关系操作化）

v5 已有：大运成格变格、流年/月建干支并看、岁运战冲和好、透清、贞元代际、寿元三关。

v6 增量：

1. **岁运关系四分类**（《滴天髓》岁运章操作化）：
   - 战：运伐岁/岁伐运，看日主喜谁、得不得党；
   - 冲：运冲岁/岁冲运，看冲的轻重与救应（会合解冲）；
   - 和：干支合，看合掉的是喜是忌；
   - 好：比和（庚辛、申酉），看日主喜阴喜阳。
2. **太岁纪律**（《三命通会》《渊海子平》《神峰通考》一致）：岁伤日干祸轻、
   日犯岁君灾重（五行有救反招财）；真太岁/征太岁；岁运并临
   （羊刃七煞凶、财官印绶吉）；伏吟返吟；晦气（日干合太岁）。
3. **大运流年分工**：大运重地支、流年重天干（"岁用天元，运用地支"）；
   交运如接木（转角接木：丑寅、辰巳、未申、戌亥交界处换运）
   ——引擎输出交运提醒，不作硬性吉凶。
4. **盖头与动静**（《神峰通考》）：运干为盖头先论；天干只与天干作用、
   地支只与地支作用（动攻动、静攻静）；墓库须对冲之字开锁。
5. **寿元/大限候选规则**（《三命通会》认格局生死之歌）：
   印绶见财行财运又见死绝、正官见杀及伤官刑冲破害岁运相并、正财偏财见比肩
   分夺又见岁运冲合、伤官财旺身弱官杀重见混杂冲刃岁运又见——四条
   作为"寿元三关"的补充候选，按"一不可拘，二须敢断"执行（输出为条件句）。
6. **神趣八法**（类属从化照返鬼伏）并入外格/从化判定，与《滴天髓》从象化象对照。

## 7. M6 实证校准（断语分级与多书互证）

v5 已有：证据分级 A/B/C、基线对照、假设—反证归因、概率化输出。

v6 增量：

1. **断语三级制**：
   - S 级（结构化规则）：由干支生克/格局/岁运关系可推导，多书一致。可直接作结论骨架。
   - C 级（文化注记）：神煞、纳音、歌诀、体象诗、择日吉凶。输出必须标注"文化注记"。
   - X 级（不采用）：历史性别观断语（娼淫/奴婢/克夫）、医疗断语、以生肖/日支
     定生死的小儿关煞。**X 级禁止出现在最终输出**（用户要求时可作史料引用并加说明）。
2. **多书互证**：关键格局/岁运结论至少两书一致；冲突时按门派分歧并列，
   并在结论旁注明出处（如"子平真诠主 X；三命通会主 Y"）。
3. **谬说清单**：把《神峰通考》点名批判的格名/神煞录入"不采用"清单，
   防止模型在开放对话中自行发明"旧书格名"。

## 8. 六亲（human）v6 增量

1. 双轨保留：星位（印母/财父/官杀子女/比劫兄弟）＋宫位（年祖月父母日妻时子）。
2. 取用补充（《三命通会》）："明干有时明干取，明干无时暗中求"；
   六亲星坐生旺库禄马贵人者吉，坐刑冲空亡死绝者减力。
3. 中性化改造（《滴天髓》女命章为范本）：女命断语一律按"权威关系/产出关系"
   表述（官杀=权威约束、食伤=产出表达），并注明旧书存在性别偏见断语，BFFT 不采用。
4. 子女/婚姻的"喜神看财、喜神看官杀"（《滴天髓》夫妻/子女章）：
   不以固定十神定性，而按喜忌语境动态判定。

## 9. 星命注记（可选，默认关闭）

（《果老星宗》合编本，民国三十年集文书局版）

1. **定位**：七政四余星命是与四柱八字不同源的平行体系（依赖真实天文星历）。
   BFFT 不把星命术语混入四柱引擎，只提供可选"星命注记"。
2. **启用条件**：用户显式要求星命视角；有可靠星历数据源（外部计算七政位置、
   太阳宫、宿度）。当前引擎不实现七政推步。
3. **输出纪律**：星命注记与四柱结论**并列输出、独立标注置信度**；
   两者冲突时按"体系不同源，不作融合判断"处理，不强行折中。
4. **可借鉴结构**：恩/用/仇/难四分法（喜忌分层）与限度分段（时间窗口），
   与四柱喜用忌仇、大运分段互证——只作方法论旁证，不作数值输入。

## 10. 已知边界（v6 追加）

- 八部文献互相矛盾，任何"多书一致"只说明规则体系内部自洽，不说明预测有效。
- **同盘异命是预期**：四柱相同不代表命运相同。三书原典（三命通会时地分野、
  滴天髓生时章、神峰通考山川风气）均承认八字信息不完备，须并入
  时之先后/山川之异/世德之殊。区分维度清单与登记纪律见 calibration.md 第 5 节。
- 节气时刻仍为分钟级精度；距节气 1 小时内必须外部核对。
- 择吉神煞、纳音、神煞吉凶断语对商业/人生结果**无因果效力**，
  仅作文化注记；BFFT 不据此做投资、医疗、婚恋决策。
- 星命注记（果老星宗）依赖天文星历推步，当前引擎不实现七政四余计算；
  若启用需外部星历数据源，并单列置信度。

# BFFT 完整命理报告模板（三盘交叉 · 七维度）

> 版本：v7.14 ｜ 用途：用户提供出生信息（或现成八字）→ 一键生成结构化完整报告。
> 本模板对"三盘交叉+七维度"需求做了 BFFT 纪律改造：每项标注证据级别
> （S=结构化规则 / C=文化注记 / X=禁止输出），**不生产无法验证的精确断言**。
>
> 一键入口：`python scripts/report.py --dt "1990-01-01 10:00" --tz 8 --lon 116.4 --gender male`
> 只给八字：`python scripts/report.py --pillars "庚子 丁亥 庚午 壬午" --gender male`
> （缺出生日期则起运岁数/真太阳时不可算，报告会显式标注缺口。）

## 0. 输入纪律（M0）

- 必须项：出生年月日时（公历；农历需先换算）+ 性别 + 出生地（经度/城市）。
- 只给四柱八字时：可推十神/藏干/关系/命宫/胎元/大运干支序列，但**起运岁数、
  真太阳时、流年交运点不可算**——报告标注缺口，不猜。
- 历法：1582-10-15 前默认儒略历；英国 1752/俄国 1918 等切换点人工确认。
- 数据来源标注：每条外部事实（如出生时间出处）注明来源 URL 与抓取时间。

## 1. 三盘交叉（部分能力）

- **主盘 = 四柱**（BFFT 自研引擎，零依赖，三重独立参照已验证）。
- **紫微、星盘：BFFT 未实现**。需要交叉时接入外部排盘（如 iztro 紫微），
  输出与四柱并列、独立标注，**不作强行融合**（v7.12 纪律：体系不同源）。
- 交叉原则：三方一致的结论置信 +1 档；冲突时并列输出+注明分歧，不下统一结论。

### 1.1 相貌/体表特征（C 级，禁止精确断言）

- 无任何古籍规则可可靠推出"胎记/痣的具体位置与颜色"——**此项不做预测**。
- 允许输出：五行体质倾向（木主修长、火主红润、土主敦厚、金主方正、水主圆润），
  标"文化注记，个体差异远大于五行倾向"。

### 1.2 关键事件验证（改为事前判据，拒绝事后拟合）

- 禁止"推测 2-3 件过去事件等你核对、不符就继续调"——那是事后拟合，
  任何事件都能被讲圆（famous20 20/20 相容已证伪其信息量）。
- 正确姿势：输出 2-3 条**未来时间窗判据**，登记 `predictions/<name>.json`
  （含 base_rate、falsify、deadline），git 提交时间即事前证明，
  到期按第三方事实回填 hit/miss。

## 2. 命局核心分析（S 级为主）

- 身强身弱：月令得令/失令 + 根气（本气>中气>余气）+ 得势，输出
  "偏弱/中和偏弱/中和/中和偏强/偏强"+依据（ren_yuan 人元司令作定性参考）。
- 喜忌：按 M3 病药八法（雕枯旺弱 × 损益生长），先定病后定药。
- 十神/体用：原局十神表+完整干支关系（合冲刑害破半合自刑，v7.12 表）。
- 事业/财富/情感三维度落地建议：行业选择（十神取象）、理财（财星喜忌）、
  相处模式（宫位+十神）——给方向区间，不给"具体某股某盘"。

## 3. 格局（S 级 + 从格双轨）

- 成格判定：月令定格→顺逆用神→成败救应→相神→纯杂高低（M2 全流程）。
- 从格嫌疑：**双轨并列**（身弱 vs 从格，各列成立条件与后果），不强行二选一
  （yueyuan 四态纪律，v7.12 吸收）。
- 格局缺陷与风险：列"破格条件"（如正官格忌伤官透、忌刑冲），
  给规避方向；不给命定式断语。

## 4. 大运（S 级）

- 每步 10 年列表：干支+起止年+交运标注（十年一运为默认；五五分看流派分歧并列）。
- 各步定性：按原局喜忌给"进取/稳健"建议与需警惕项（健康/财务/人际），
  条件句输出；健康仅限体质倾向（C 级），不输出疾病诊断（X 级）。

## 5. 七维度（分级输出）

| 维度 | 级别 | 输出内容 |
|---|---|---|
| 父母家庭 | S+C | 宫位（年柱）+星位（印/财）；关系亲疏给倾向；经济状况仅"祖荫有无"倾向 |
| 事业 | S | 官杀+财+印十神组合；适合领域、地域方位（五行分野）；吉凶年份=判据化 |
| 婚姻 | S+C | 配偶"特质倾向"（C 级，不给具体职业/身高）；相遇时间窗=判据化；**前世羁绊=不可验证，仅作文学表达并显式标注** |
| 财富 | S | 财星+食伤生财路径；储蓄/投资倾向；破财点（比劫夺财等结构）；理财方向 |
| 个人特质 | S+C | 十神性格组合（S）；学习/沟通/抗压倾向；MBTI 类标签不输出（无规则依据） |
| 健康 | C | 五行体质+易感倾向（金木交战筋骨、火炎心血管等），**明确"非医疗建议，就医以医生为准"** |
| 子女+宠物 | C | 子女数量：旧书长生沐浴歌为低置信断语，**不给精确数字**，只给"子女缘强弱"倾向；宠物缘分=文化娱乐注记 |

## 6. 输出格式（report.py 生成骨架）

1. 命盘数据表（四柱/十神/藏干/关系/命宫/胎元/人元/大运流年）
2. 五大板块（§1-§5 标题与纪律提示），分析段落由 Agent 按本模板填充
3. 判据清单（≥2 条 A 级事前预测）
4. 底部固定声明：文化娱乐性质，不作为投资/医疗/婚恋决策依据

## 1. 方法纪律（先说清什么能证明、什么不能）

- **过去年份**（2006—2024）：规则与预测在事实表编译**之前** commit。但规则设计者
  （人）知道她的履历，且样本只有 1 人 19 年——所以这只是**伪事前回测（B 级）**，
  演示流水线，不构成模型有效性证据；`verify.py` 已按 git 首次提交时间把这些判据
  标为 late，不计入 A 级。
- **未来年份**（2027—2031）：commit 于 2026-08-15，早于所有窗口起点，是**真正的事前
  登记（A 级）**。其中 13 条 A 级判据里 10 条因模型概率 ≤ 基线被标 low_information
  （命中也不提供信息量），3 条非低信息量（商业节点）。
- **出生时辰 DD 级**（5:17 vs 8:36 冲突）：逐年规则只依赖年/月/日三柱与两版一致的
  大运序列；时柱、命宫、交运日不进入规则。换 05:17 版，本表所有数值不变。

## 2. 逐年规则（rulebook v0，先于事实固定）

- 专辑概率 = 0.30 + 干关系权重（食伤 +0.12 / 印 +0.08 / 财 +0.06 / 比劫 +0.04 /
  官杀 +0.04）+ 日支关系权重（冲 +0.05 / 合·半合 +0.04 / 伏吟 +0.03 / 穿·刑 +0.02）
  + 岁运并临 +0.03 / 岁运冲合 +0.02，截断 [0.10, 0.80]。
- 巡演概率 = 0.20 + 干关系权重（官杀 +0.08 / 食伤 +0.06 / 财 +0.03 / 比劫 +0.02 /
  印 +0.00）+ 日支权重（伏吟 +0.06 / 冲 +0.05 / 合 +0.04 / 穿·刑 +0.02）
  + 岁运项，同上截断。
- 判据定义（公开可核验）：`album`=该年发行全新录音室专辑（重录版不算）；
  `tour`=该年举办新巡演首场；`biz`=该年重大商业/版权/合约公告。
- 基线：专辑 0.50（2006—2024 实测 10/19≈0.53）、巡演 0.32（6/19）、商业节点 0.30。

## 4. 打分（Brier 与技巧分数）

| 判据 | n | 命中 | 模型 Brier | 基线 Brier | 技巧分数 |
|---|---|---|---|---|---|
| 专辑 | 19 | 10 | 0.2760 | 0.2500 | **−0.104**（差于基线） |
| 巡演 | 19 | 6 | 0.2059 | 0.2161 | **+0.047**（略优于基线） |

诚实解读：

1. **专辑判据模型劣于基线**：19 年里模型概率全部 ≤0.49，而真实新专辑率 10/19=0.53。
   规则把"食伤年=产出年"拉高了少数年份，却系统性低估了整体频率——直接后果是
   2027—2031 的专辑判据全部自动标 low_information，命中也不算数。
2. **巡演 +0.047 ≈ 噪声**：n=19、单一样本、规则设计者知道历史，且换一版同样
   讲得通的权重符号就会翻转。按项目纪律（技巧分数须显著大于 0 且需多实体样本），
   这不足以称为"模型有效"。
3. **这张表的真正价值是流程演示**：预测先于事实 commit → 事实表后编译 →
   Brier/技巧分数对照基线。同样的流水线对鸣潮/乃琳跑，才可能积累有效证据。
